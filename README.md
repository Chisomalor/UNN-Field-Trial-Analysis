# 🌱 UNN Field Trial Analysis

## About This Project
This project analyzes a field trial experiment 
looking at how different organic soil amendments 
affect plant height. It was inspired by the kind 
of agricultural experiments I studied at the 
University of Nigeria, Nsukka.

## What I Analyzed
- How poultry manure affects plant growth
- How pig manure affects plant growth
- Comparing both to a control group
- Which treatment produced the tallest plants

## What I Found
- Poultry manure: average plant height 50cm
- Pig manure: average plant height 48cm
- Control group: average only 20cm
- Both manures significantly improved plant growth

## Tools Used
- R | ggplot2 | Posit Cloud

## Why This Matters
Organic soil amendments are affordable for 
smallholder farmers in Nigeria. Understanding 
which ones work best can practically improve 
crop production.
